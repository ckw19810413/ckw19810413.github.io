### 第一幕：九天玄隕與通天神臂閣

在大鈞仙朝的萬里疆土之東，連接著浩瀚無垠的虛宿海。

海岸之畔，高聳著一座令凡夫俗子望之屏息的萬丈金屬神構：**「通天神臂閣」**。
神閣拔地千丈，通體由萬載玄鐵與秘銀符文澆鑄而成。兩條粗壯無比的機械巨爪，宛如天神合掌垂落的筷箸，凌空懸於半空之巔。

大鈞仙朝的修士們自古便掌握御空巡天之術。他們打造出橫渡星漢的龐大仙舟：**「燭龍飛舟」**。
飛舟長達數十丈，重逾千鈞，每一次遠征域外星海歸來，都必須從萬丈高空呼嘯墜落，在觸地前的最後數息之內，將恐怖的下墜動能徹底化解，穩穩懸停於那兩條機械巨臂之間，被其凌空合抱。

這被仙朝工匠稱為「毫釐擒龍」。

倘若飛舟偏離半尺，便會將整座神閣撞得灰飛煙滅；倘若降落速度未能歸零，巨臂合抱之時，鋼骨便會寸寸折斷；而倘若在半空中遲疑了半步，飛舟便會徑直砸向礁石海岸，炸裂成萬道赤焰。

而在這場驚心動魄的降落中，最致命的難題，不在於呼嘯的狂風，也不在於萬有引力的拉扯，而深藏於燭龍飛舟的心臟：**「太微離火爐」**之中。

### 第二幕：中空神火與不可逾越的凹陷魔咒

燭龍飛舟的底部，鑲嵌著三十三具吞吐天地的離火噴口。
然而，太微神火乃天地極陽之靈，它的吞吐噴湧，受制於兩道無可撼動的物理鐵律：

其一，名為**「裂空爆炎界」（極大推力 $T_{max}$）**。若火爐靈力催動過甚，爐壁承受的熱應力超出玄鐵極限，整個飛舟便會凌空炸裂；
其二，更為致命的，名為**「寒煞冰凝界」（極小推力 $T_{min}$）**。神火之燃燒，需仰賴液態靈髓的高壓噴注與自持燃燒漩渦。一旦靈髓供給降至一定臨界以下，漩渦崩解，極地寒煞倒灌，火爐便會瞬間熄滅，且在下墜的狂飆氣流中永遠無法再次點燃！

這便意味著：**神火的推力大小，絕不能隨心所欲地從零平滑調節。**
它的推力向量，要麼徹底為零（熄火自由落體），要麼其力量強度必須嚴格落在一個「中空的環形殼體」之內：
$$0 < T_{min} \le \|\mathbf{T}\| \le T_{max}$$

在司天監的算籌幾何學中，長老們將這稱為**「空心甜甜圈的凹陷魔咒」**。

尋常修士若要尋找一條平緩的山道，只需順著山勢坡度緩步向下（梯度下降）。若整座山峰是個圓潤凸起的巨碗（凸集合），任何盲人只要往低處邁步，最終都必然匯聚於谷底唯一的真水池（全局最優解）。
然而，神火推力空間的中間，硬生生被挖出了一個空洞：推力不能太小，推力方向又被鎖定在朝向地面的防側翻錐面之內。

這導致飛舟的運動方程在幾何拓撲上變成了一個充滿懸崖、深淵與虛假窪地的**「非凸泥潭」**。

司天監首座**太史玄翁**，率領數百名老算匠盤坐於算天殿的「天衍玄玉台」旁。
他們使用的，乃是代代相傳的「尋峰梯法」（順序二次規劃 SQP）。
每當燭龍飛舟從九天之巔帶著滾滾濃煙砸向大地，飛舟上的留音符便瘋狂閃爍，向玄玉台索求下一刻的推力方向與開火時機：
「十息後入雲海！求算神火噴吐分量！」

然而，算天殿內卻是一片冷汗涔涔。
「報！算籌陷入第三千二百個局部偽谷，推力向量在左右兩翼劇烈振盪！」
「報！尋優迭代已至第二百輪，運算耗時超出三毫秒限制，數值發散！」
「轟隆！」

在過去數次推演與小試中，飛舟無一例外不是因演算法無法及時收斂而重重砸入深海，便是因誤判了點火高度，在離地百丈處耗盡了最後一滴靈髓，慘烈墜毀。

太史玄翁仰天長嘆：「非凸之障，乃是天道留給凡人的死局。神火中空，不可求解；若要強行精確計算，百次呼吸亦不能定一軌。然墜天金烏，何曾給過我們半息的喘息？」

雲淵手中沒有繁複的算盤，只拿著一根細長的玉尺與一卷空白的羊皮圖卷。
他走到天衍玄玉台中央，當著諸位長老的長鬚，在羊皮紙上畫了一個空心的神火圓環：
「諸位尊長，你們之所以被困在死局中，是因為你們被真實世界的殘酷束縛了靈智。你們看這空心之環，中間那一圈溫和的微弱之火（$0 \le \|\mathbf{T}\| < T_{min}$），天地法度嚴禁神火在其中燃燒，所以你們在算籌中也將它視為萬劫不復的深淵，拼命在空心邊界外繞道尋路，這才跌入無數局部陷阱。」

太史玄翁怒斥：「無知小兒！天地法度如此，太微離火低於下限便會熄火自毀，不在邊界外算，難道你敢叫火爐點燃那不存在的微火嗎？」

雲淵微微一笑，提起硃砂筆，竟毫不猶豫地在那個空心圓環的中央，**狠狠塗滿了濃墨**！
原本中空的圓環，瞬間變成了一個**渾然一體、毫無缺口的實心圓盤**！

「我的法門只有八個字：**以實填虛，虛境放寬**。」
雲淵朗聲道：
「我們在算籌推演的靈台世界裡，撕毀那條『推力不得低於下限』的禁律！我們允許算籌任意選取從零到極限的所有推力大小！不僅如此，我引入一道虛擬的幽冥影變量 $\Gamma$，將原本空心的推力約束，放寬為一道完美無瑕的**二階錐面（Second-Order Cone）**：
$$\|\mathbf{u}\| \le \Gamma, \quad \rho_{min} \le \Gamma \le \rho_{max}$$
如此一來，非凸的絕境，瞬間化作廣袤平滑的**嚴格凸世界**！
在凸世界裡，不存在任何局部偽谷；無論從哪裡起步，內點法（Interior Point Method）都能在區區十幾次矩陣求逆之內，以多項式時間確定無疑地直抵唯一全局極限！」

「荒謬！欺天！」
長老們拍案而起，怒不可遏：
「你在推演時允許飛舟使用溫和的微火，神舟之靈便會貪圖省力，算出一條『輕柔慢落』的虛妄軌跡！可現實中沒有溫和的微火！一旦真實飛舟照著這份軌跡下達敕令，命火爐噴出三成之力，火爐便會當場熄滅！十萬修士之性命，豈能由你在紙上作弊填補？」

雲淵面不改色，迎著眾人的怒火，拔出腰間長劍，在玄玉台的地磚上斬出一道筆直的刻痕：
「這不是作弊，這是天地至理的**無損代價**！
我早已以仙朝開國祖師的『極小值原理』推演過協態軌跡：只要我們的目標是**『耗費最少靈髓、以最快速度止煞』**，重力之弦便會像一張無形的大弓拉滿虛空。
在那道緊繃的協態向量牽引下，實心圓盤中央的每一滴虛妄之火，對總耗能來說都是極其昂貴的浪費！
我以神魂立誓：**在整條全局最優軌跡之上，最優的算籌將會本能地鄙棄中央的溫和虛火，它所選出的解，將以百分之百的絕對機率，嚴格貼死在真實的物理邊界之上！虛境雖開，神火不落空心！**」

### 第四幕：千丈驚瀾與無損真經的最後對決

「報！」

一次預測、一次中心路徑追蹤、一次原始-對偶內點迭代……
**一毫秒、兩毫秒、三毫秒！**
一條閃耀著璀璨金光的優雅軌跡，宛如天神親手繪製的玉帶，在虛空中轟然鋪開！

那軌跡不僅滿足下滑坡度的避障錐，更精準將終端速度鎖死在零點零分。

太史玄翁撲到光幕前，枯瘦的手指劇烈顫抖著指向數據流：
「看……看推力指令！神火噴吐分量是多少？它有沒有選取空心處的微火？有沒有？」

所有人都屏住了呼吸。
只見在那條由數千個時間節點構成的軌跡上：
在第一階段，飛舟俯衝轉體，推力數值顯示為：**零（自由落體翻滾）**；
在第二階段，反推引擎驟然轟鳴，推力數值從零瞬間躍遷至：**七成（恰好等於極小推力下限 $T_{min}$）**；
隨後，隨著高度驟降，推力直線攀升至**九成五、十成（頂格極大推力 $T_{max}$）**；
在最後懸停的剎那，推力在精確的節流曲線上升降，但其模長數值與影變量 $\Gamma$ 之間的差距是：
$$|\|\mathbf{u}^*\| - \Gamma^*| < 10^{-14}$$

**嚴格相等！**
在全航程數千個計算斷面上，沒有任何一個點落在禁止燃燒的「空心溫和微火」之中！
那看似放開了一切限制、允許微火存在的虛擬實心圓盤，在全局最優化的物理法則驅動下，其解竟然奇蹟般地、天衣無縫地**百分之百錨定在真實硬體所允許的極限邊界上**！

### 第五幕：金烏懸停，雙臂合龍

海天之間，巨獸降臨。

三十三具太微離火噴口在最後八百米高度同時爆發出刺目的藍白色烈焰。狂暴的衝擊波將海面壓出一個直徑千米的巨大凹陷白浪。
飛舟那龐大如山嶽的艦身，在空中進行了一次不可思議的矢量擺動，精準契合著滑坡錐的邊界，筆直地插入通天神臂閣的正中央。

五百米、兩百米、五十米、十米……
火焰咆哮聲中，飛舟的下墜速度從每秒數百米，以肉眼可見的完美加速度平滑遞減。
最終，在離海面三百丈的虛空之中，速度指針悄無聲息地歸零。
飛舟懸停於半空，宛如一隻收攏羽翼的金烏，紋絲不動。

**「轟咔！」**

### 真相揭曉：現代控制理論之巔：無損凸化定理（Lossless Convexification）

故事中驚心動魄的「燭龍飛舟凌空捕獲」，正是 2026 年底震撼全球工程界的真實科技事件：**SpaceX Starship（星艦）超重型助推器成功被 Mechazilla 發射塔「筷子機械臂」精準捕獲**的深層數學投影。

在航天工程與運載火箭的動力下降段（Powered Descent Guidance, PDG），降落問題本質上是一個**終端時間自由、燃料最優、高維度受限的非線性動態控制問題**。

#### 1. 物理現實中的非凸深淵（The Non-Convex Impasse）

火箭在終端著陸時，必須滿足以下物理動力學：
- **質點運動方程**：
  $$\dot{\mathbf{r}}(t) = \mathbf{v}(t)$$
  $$\dot{\mathbf{v}}(t) = \frac{\mathbf{T}(t)}{m(t)} + \mathbf{g}$$
  $$\dot{m}(t) = -\alpha \|\mathbf{T}(t)\|$$
  其中 $\mathbf{r}$ 為三維位置，$\mathbf{v}$ 為速度，$\mathbf{T}$ 為推力向量，$m$ 為火箭時變質量，$\alpha = \frac{1}{I_{sp} g_0}$ 為燃料消耗率。

- **致命的控制約束：推力下限**：
  火箭引擎（如 SpaceX Raptor 猛禽發動機）使用渦輪泵與再生冷卻，其燃燒室有嚴格的流體動力學下限。若節流低於額定推力的 40%~50%，燃燒室將發生聲學不穩定震盪導致熄火或爆炸。因此：
  $$0 < T_{min} \le \|\mathbf{T}(t)\| \le T_{max}$$
  令加速度控制量 $\mathbf{u}(t) = \frac{\mathbf{T}(t)}{m(t)}$，質量對數 $z(t) = \ln m(t)$，推力約束變為：
  $$T_{min} e^{-z(t)} \le \|\mathbf{u}(t)\| \le T_{max} e^{-z(t)}$$

**為什麼這是災難性的？**
約束集 $\{\mathbf{u} : \|\mathbf{u}\| \ge T_{min} e^{-z}\}$ 定義了一個**中空的甜甜圈/球殼**。
如果兩個可行的推力向量 $\mathbf{u}_1$ 與 $\mathbf{u}_2$ 都滿足條件，它們的中點 $\frac{\mathbf{u}_1 + \mathbf{u}_2}{2}$ 極可能落在中空區域（推力過小），從而不滿足約束！這在數學上定義了**非凸集合（Non-convex Set）**。

在非凸優化中：
1. 存在無數個局部極小值（Local Minima）；
2. 傳統尋優演算法（如 SQP、梯度法）收斂時間未知，具有指數級複雜度；
3. 當火箭以每秒數百公尺的高速墜落時，彈載電腦必須在 10~50 毫秒的週期內給出保證可行且全域最優的解答。**任何非確定性的演算法，都等同於讓火箭在半空中擲骰子。**

#### 2. 神來之筆：無損凸化（Lossless Convexification）

2007 年至 2011 年間，土耳其裔美籍控制學家 **Behçet Açıkmeşe**（曾任職於 NASA JPL，現為華盛頓大學教授）與 Lars Blackmore 等人發表了開創性的論文，提出了震撼航太控制領域的**無損凸化定理**。

他們引入了一個鬆弛標量變量（Slack Variable）$\Gamma(t)$，代表推力加速度的模長上限，並將非凸問題重新表述為：
1. 將推力下限約束從幾何空間中移開，轉而約束標量 $\Gamma$：
   $$\rho_1(t) \le \Gamma(t) \le \rho_2(t)$$
2. 將加速度向量約束放寬為：
   $$\|\mathbf{u}(t)\| \le \Gamma(t)$$

請注意這微小而深刻的改變：
$\|\mathbf{u}(t)\| \le \Gamma(t)$ 定義的是一個標準的**二階錐（Second-Order Cone，又稱洛倫茲錐 / Lorentz Cone）**！
二階錐是一個嚴格的**凸幾何體（Convex Set）**！

連同線性的降落錐坡（Glide Slope Constraint）與推力指向錐約束，原本不可求解的非凸控制問題，被完全轉化為一個標準的**二階錐規劃（Second-Order Cone Programming, SOCP）**！

```
     非凸推力空間 (中空甜甜圈)              凸鬆弛後的二階錐 (實心圓錐)
            ▲ u_y                               ▲ Γ (鬆弛上限)
            │      可行區域                     │       /
       ┌────┴────┐                              │      /  可行錐體內部
       │  ┌───┐  │                              │     /   ||u|| <= Γ
       │  │ x │  │  (中間不可行)                │    /
       │  └───┘  │                              │   /
───────┴─────────┴─────► u_x             ───────┴──/───────► ||u||
      T_min    T_max                               0
```

#### 3. 數學證明：為什麼放寬後「毫無損失」？

所有人最初都會提出與寓言中長老相同的質疑：
*「你允許 $\|\mathbf{u}(t)\| < \Gamma(t)$，優化器難道不會作弊，選擇 $\|\mathbf{u}\| = 0$ 讓火箭白白掉下去，同時讓 $\Gamma$ 假裝消耗燃料嗎？」*

Açıkmeşe 等人運用**龐特里亞金極小值原理（Pontryagin's Minimum Principle, PMP）** 給出了無可辯駁的嚴格證明：

在燃料最優目標下，性能指標為最小化燃料總消耗：
$$J = \int_0^{t_f} \Gamma(t) \, dt$$

構建系統的哈密頓量（Hamiltonian）：
$$\mathcal{H}(\mathbf{r}, \mathbf{v}, z, \mathbf{u}, \Gamma, \boldsymbol{\lambda}) = \Gamma + \boldsymbol{\lambda}_r^T \mathbf{v} + \boldsymbol{\lambda}_v^T (\mathbf{u} + \mathbf{g}) - \lambda_z \alpha \Gamma + \mu (\|\mathbf{u}\| - \Gamma) + \dots$$

其中 $\boldsymbol{\lambda}_v(t)$ 為速度協態向量（Costate Vector）。
根據極小值原理，在任何最優軌跡上，控制輸入 $(\mathbf{u}^*, \Gamma^*)$ 必須在約束錐集內將哈密頓量極小化：
$$\min_{\|\mathbf{u}\| \le \Gamma} \left[ \boldsymbol{\lambda}_v^T \mathbf{u} \right]$$

柯西-施瓦茨不等式（Cauchy-Schwarz）與內積幾何性質直接指出：
要讓 $\boldsymbol{\lambda}_v^T \mathbf{u}$ 達到極小值，向量 $\mathbf{u}$ 必須**沿著協態向量 $\boldsymbol{\lambda}_v$ 的嚴格反方向**，並且**長度必須頂到允許範圍的最大邊界**！
$$\mathbf{u}^*(t) = -\Gamma^*(t) \frac{\boldsymbol{\lambda}_v(t)}{\|\boldsymbol{\lambda}_v(t)\|}$$

這直接證明了：只要 $\|\boldsymbol{\lambda}_v(t)\| \ne 0$，就有：
$$\|\mathbf{u}^*(t)\| = \Gamma^*(t)$$

Açıkmeşe 進一步證明了系統協態的非奇異性（Non-singularity）：由於 $\dot{\boldsymbol{\lambda}}_v = -\boldsymbol{\lambda}_r$ 且 $\dot{\boldsymbol{\lambda}}_r = \mathbf{0}$，協態向量 $\boldsymbol{\lambda}_v(t) = -\mathbf{c}_1 t + \mathbf{c}_2$ 是一條隨時間變化的三維直線。一條直線穿過原點（即 $\|\boldsymbol{\lambda}_v(t)\| = 0$）的時刻，在測度意義下**最多只有一個孤立的瞬時點（Measure Zero）**！

**結論驚世駭俗**：
在整條連續時間的最優控制軌跡上，鬆弛不等式 $\|\mathbf{u}(t)\| \le \Gamma(t)$ **在幾乎所有時刻都以嚴格等號成立（Tight Everywhere）**！
鬆弛後的凸問題的最優解，就是原非凸問題的真實物理最優解。這項理論因此被冠以**「無損（Lossless）」**之名！
