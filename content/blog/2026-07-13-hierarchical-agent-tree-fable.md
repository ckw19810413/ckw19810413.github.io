在東方的海峽之外，有一座島嶼王國，被一片名為「千嶼海」的汪洋環抱。要抵達海對岸那座繁榮的貿易港口，船隊必須穿越一千座嶼礁交錯的島群。潮水每日翻覆，礁石會移動，霧氣說來就來，沒有兩天的海面是相同的。

王國歷來由「導航司」派領航員率領商隊渡海。幾百年來，商船安全往來，從未有一艘沉沒。

---

那年，一位年輕的導航天才自告奮勇，要率領王國最重要的黃金船隊渡海。他天資極高，花了一整年時間踏勘了每一段航路，把每一座礁石、每一股暗流、每一次轉彎都記在一本厚厚的航海圖上——共一萬二千三百四十七步，一步一註，從起錨到靠岸，絲毫不差。

「只要我牢牢記住這張圖，」他對國王說，「我一步一步照著走，便絕無失誤。」

國王允了。船隊啟航。

頭三天，一切都如圖所繪：第一步、第二步、第三步……船隊平穩前行。可是到了第七天，海面起了霧，圖上第七頁被海水浸濕，墨跡暈開。年輕領航員慌了：「我必須回到第五頁，重走那段路，重新對準座標。」

於是船隊往回走了兩天。

回到第五頁，他重新出發。可是霧還沒散，潮水又漲了。第八天的暗流比圖上記錄的偏了三度。他咬牙，再退回第三頁重走。

每退回一次，前面累積的航程就全部作廢。船員們開始恐慌：「我們不知道自己在哪，也不知道要去哪，只知道自己正在倒著走。」

船隊在一個無名小島上擱淺了四十三天。

---

這一天，島上漂來一條小舟。舟上坐著一位頭髮全白的老人，他雙目全盲，左手拄著柺杖，右手卻始終穩穩地托著一座小小油燈。

「你是那個畫了一萬步圖的人？」老人問。

「是。但海變了，圖沒變。」年輕領航員苦笑道。

老人搖了搖頭，把油燈舉高。燈火在夜霧裡照出一小圈光，只夠看清腳下三步。

「你為什麼要記住一萬步？」老人問。

「因為只有把所有路都記住，才不會走錯。」

「你記住了所有路，但你沒有記住『路是怎麼長出來的』。」老人說，「海不是死的。你用一張死圖去追一片活的海，怎麼追得上？」

老人從懷裡掏出七張薄紙，鋪在船甲板上。

「我用了四十年，把這片海分成七段。」他說，「第一段：出島群。第二段：過東流。第三段：穿霧峽。第四段：過暗礁場。第五段：繞南島。第六段：穿風帶。第七段：進港。每一段，我只派一位『段長』負責，他只需要懂得自己那一段——潮水的節律、礁石的位置、霧季的規律。他不需要知道全貌，也不需要知道其他六段的事。」

「那出了什麼狀況呢？」年輕人問。

「比如霧封了第三段，段長就在他自己那一段裡找替代的路——他比任何人都懂第三段，所以他能找到。他不需要把消息傳回總舵重畫全圖。他只需要在段界處點起信號火，告訴我『我到了』，我就可以派下一段的段長接應。」

「可如果一段完全走不通呢？比如南島的暗礁被海嘯掀翻了，第五段根本沒法走？」

老人笑了：「那才麻煩。那時候，我要在塔上重新做一個決定：第五段是繞開還是等海嘯退。這是『我的』決定——因為需要跨段資訊，只有站得夠高的人能做。但我只需要做這一個決定。剩下的，交給段長。」

年輕人沉默了很久。

「那你呢？」他問，「你在塔上，看不見海，你怎麼知道現在走到哪一段了？」

「我不需要知道。」老人說，「我只需要知道：第三段的火沒亮，而第五段的火亮得晚了三天——那就是信號。我發出指令：『第四段段長，延遲兩日，等第五段段長完成轉運。』我不看海。我只看火。」

「可那些段長……他們怎麼知道該怎麼辦？」

「每個人本段的日記。」老人指了指自己的燈，「每一段都有一本『舊志』——幾十年前某位段長在同樣的位置遇到同樣的霧，他記下了：往左三海里，繞礁石，兩日可過。新的段長遇到同樣的局面，翻開舊志，不用重新摸索。他不需要重新『發明』那一段怎麼過，他只需要把經驗帶進來，然後做下一步的局部決定。」

「而各段之間呢？前一段的水情，後一段怎麼知道？」

「煙火。每一座嶼上有望台。前一段的段長在轉手前，點一堆特定的煙——顏色代表風向，高度代表浪高——後一段的段長看了煙，就知道我交接給你的船是幾分幾分風、幾分幾分浪。你不需要重新看一遍整片海，你只需要讀那一堆煙。」

年輕人低頭。他看著那七張薄紙，忽然明白了。

「所以整張海圖，從來都不在任何一個人的腦子裡。」他說。

「對。」老人說，「它分散在七個人心裡。每個人只知道自己那一段，但七個人合起來，比任何一個人都更懂這片海。」

---

那年冬天，海難季來得比往年更早。年輕導航員的備用圖再次被海風撕毀。他沒有再哭。

他讓七位段長各就各位。

第三段遇霧，段長改走北側暗水道——用掉多兩日，但安全通過。第五段的海嘯比預期提前了四天，第五段段長在段內自行繞開主航路，用了一天半補回進度。只有第四段與第六段交界處的洋流方向突然改變，觸發了燈塔上的「重規」信號，老人在塔上重排了兩段的順序，船隊用了額外的三小時，但沒有損失任何一艘船。

船隊到港那天，全艦無一傷亡，比往年快了一整天。

年輕導航員跪在老人面前：「你從來沒有畫過一張完整的圖，為什麼你比我更接近『不迷路』？」

老人把油燈遞給他。

「因為你試圖用一個腦子裝下一整片海。我讓每一雙眼睛只看自己那一步，讓每一層只做自己那層的決定。整張圖從來不存在於任何一個地方——它只在交接的瞬間，在兩盞燈之間的煙裡，短暫地存在過。這才是海真正存在的樣子。」

## 揭曉與概念解析

這個故事隱喻的是強化學習與人工智能領域中一個研究生級別的架構範式：**分層智能體樹（Hierarchical Agent Tree）**，具體對應 2026 年韓國研究團隊發表、已被 AAMAS 2026 收錄的工作 **ReAcTree**（*ReAcTree: Hierarchical LLM Agent Trees with Control Flow for Long-Horizon Tasks*, arXiv:2511.02424）。

### 概念本質

處理**長時程（long-horizon）複雜任務**時，單一扁平 LLM 智能體（如經典 ReAct 循環：思考→行動→觀察，反覆迭代）面臨兩個根本瓶頸：

- **上下文腐蝕（context rot）**：步數越多，歷史觀察、推理軌跡與失敗分支堆積越多，模型的有效注意力被稀釋，決策質量隨步數遞減。
- **信用分配失靈（credit assignment problem）**：在一個長序列中，若最終失敗，扁平智能體很難定位究竟是哪一步出了問題。

**ReAcTree** 的核心方法是把任務做**樹狀分解**：

- 每個節點是一個 LLM 智能體，負責對其子目標進行推理（Reason）與行動（Act）——也就是把 ReAct 循環**遞迴嵌套**在樹的每個節點上；
- 節點之間由**控制流節點**（control-flow nodes）連接：條件分支（if/else）、循環（while/until）與順序銜接。控制流節點決定「何時、由誰接手下一步」，但不直接執行具體動作；
- 整棵樹是**動態生長**的（dynamically constructed）：只有當子目標被觸發時才生成對應的子智能體，而非預先展開全樹。

此外，ReAcTree 整合了兩套互補的記憶系統：

- **情景記憶（Episodic Memory）**：每個智能體節點檢索與當前子目標相似的歷史成功/失敗樣例（subgoal-level exemplars）作為 in-context 示例注入，讓智能體「想起」類似子任務的最優解法；
- **工作記憶（Working Memory）**：兄弟節點之間共享環境觀察（observations），避免重複探測同一塊區域——類似故事裡「前一段點煙、後一段看煙」的機制。

在 WAH-NL 與 ALFRED 基準測試中，ReAcTree 搭配 Qwen 2.5 72B 模型在 WAH-NL 上達到 **61% 的目標成功率**，幾乎是 ReAct 基線（31%）的兩倍。

### 故事隱喻對照表

| 寓言中的元素 | 對應的技術概念 |
|---|---|
| 千嶼海（整片海域） | 長時程任務空間（long-horizon task） |
| 年輕導航員的一萬步全圖 | 扁平策略（flat ReAct trajectory）：所有決策在單一層級展開，上下文隨步數線性膨脹 |
| 七段分割 | 分層任務分解；每段對應一個**選項（option）**，即 Sutton–Precup–Singh 框架中的三元組（初始化集、局部策略、終止函數） |
| 段長（各段專屬導航員） | 子智能體節點（sub-agent / option）：擁有自己的局部策略，在有限時間尺度內獨立運作 |
| 段界燈塔的「信號火」 | **終止條件（termination condition β）**：當選項達成子目標或超時時觸發，控制權上層交還 |
| 老人塔頂上的「重排兩段」 | **控制流節點**（control-flow node）：if/while 邏輯，調度哪些子目標在何時展開、重排或跳過 |
| 各段「舊志」（歷史航行記錄） | **情景記憶（episodic memory）**：按子目標檢索歷史軌跡作為 in-context demonstration |
| 段間煙火（顏色=風向、高度=浪高） | **工作記憶（working memory）**：兄弟智能體間共享環境觀察，避免重複探測 |
| 「整張圖不存在於任何一個人的腦子裡」 | 分層系統的關鍵性質：全局知識是**分佈式**的，只在交接瞬間跨節點匯聚 |
| 年輕導航員退回重走、進度全廢 | 扁平策略的回溯失敗：任何一步錯誤都需要從頭重做，錯誤隨深度複利累積 |
| 段長在段內自行繞過暗礁 | 子智能體的**局部自治性**：局部故障被封裝在子樹內，不觸發全局重規劃 |

### 為什麼是「研究生水平」？

這個概念之所以在研究生課程（強化學習、多智能體系統、自動規劃）中才正式展開，是因為它同時涉及：

- **Sutton–Precup–Singh 選項框架（1999）** 的數學形式化：選項是時間上延伸的動作（temporally extended action），其價值函數在期望步長上做 Bellman 期望加權，使得分層策略可以無損失地組合；
- **動態樹構造**：不像固定 HRL 架構，ReAcTree 的樹是**按需生長**的——只有當子目標被觸發時才生成對應的智能體節點，這在計算複雜度上是關鍵區別；
- **控制流的顯式建模**：在 LLM 智能體中，「如果子目標 A 失敗則跳過、重試 B，直到 C 完成」這樣的控制流語義，在傳統 MDP 中沒有原生表示。ReAcTree 引入顯式控制流節點來處理，把「流程邏輯」與「執行」解耦；
- **雙記憶系統的交互**：情景記憶提供「怎麼做」的範例，工作記憶提供「環境現在長什麼樣」的實時狀態。二者缺一，系統退化為「有記憶的分層」而非「真正分層的智能體」。
