## 7-Day Setup Plan

Don't try to do everything at once. Here's a battle-tested 7-day setup plan, focusing on one core module per day:

### Day 1: Team Foundation Setup

**Task Checklist:**

- [ ] Create the Feishu workspace, set company logo and name
- [ ] Build department structure (Engineering, Product, Marketing, Sales, Operations)
- [ ] Import all members, set roles and permissions
- [ ] Create basic channels: #announcements, #general, #random

**Time: ~1 hour**

Day 1 is about laying the foundation. Many teams skip this and jump straight into features, but the quality of your base setup determines how well all subsequent tools integrate.

### Day 2: OKR System Setup

**Task Checklist:**

- [ ] Create company-level OKR template (using our OKR template)
- [ ] Set up Q3/Q4 Objectives and Key Results
- [ ] Build department-level OKRs for each team
- [ ] Set OKR check-in frequency (weekly recommended)

**Time: ~2 hours**

OKR is the "command center" of your digital workspace. With OKRs in place, every project and task can be traced back to your company's strategic goals. No more "what is this project even for?" confusion.

### Day 3: Project Management Kanban

**Task Checklist:**

- [ ] Create a project Kanban board for each project
- [ ] Set project workflow: To Do → In Progress → In Review → Done
- [ ] Assign project owners and task owners
- [ ] Set project deadlines and milestones

**Time: ~2 hours**

Project management is one of Feishu's most powerful features. Its built-in Kanban (project management tables in Lark Docs) lets you see the progress of all projects without switching to other tools.

### Day 4: Meeting Management System

**Task Checklist:**

- [ ] Set recurring schedules for weekly standing meetings
- [ ] Create meeting templates (including: last week review, this week goals, issues discussion, action items)
- [ ] Set up automatic meeting minutes formatting
- [ ] Train the team to use the "task assignment" feature during meetings

**Time: ~1.5 hours**

Good meetings and good documentation are different things. A meeting is "where decisions are made"; meeting notes are "the evidence for tracking decisions." With Feishu, you can generate structured meeting minutes directly during meetings and automatically create action item trackers.

### Day 5: CRM Customer Management

**Task Checklist:**

- [ ] Create a customer database (using the CRM template)
- [ ] Set the customer status pipeline: Prospect → In Contact → Quoting → Closed
- [ ] Set customer assignment rules for the sales team
- [ ] Set up the sales dashboard

**Time: ~2 hours**

CRM is the most underestimated module in Feishu. Its spreadsheet functionality offers database management similar to Airtable, and it integrates seamlessly with chat and documents. Your sales team no longer needs to switch between Excel and CRM.

### Day 6: Document Management and Knowledge Base

**Task Checklist:**

- [ ] Build the company knowledge base structure (organized by department and topic)
- [ ] Import existing documents (if any)
- [ ] Set document permission management
- [ ] Create an "New Hire Onboarding Guide" for each department

**Time: ~1.5 hours**

The knowledge base is the company's "brain." A good knowledge base lets new hires find everything they need on day one, without having to ask colleagues one by one.

### Day 7: Automation Setup

**Task Checklist:**

- [ ] Set up automatic OKR progress reminders (every Friday)
- [ ] Set up automatic notifications for overdue projects
- [ ] Set up automatic new customer assignment
- [ ] Create common forms (leave requests, expense reports, procurement)

**Time: ~2 hours**

Day 7 is the most valuable day. Once automation is set up, it runs on its own without anyone needing to maintain it. That's the true "return" of digitalization — not more tools, but "fewer repetitive management tasks."

## How to Set Up Automation Flows

The final and most critical step of digitalization is automation. Here are the three most commonly set up automation flows:

### Automation 1: OKR Progress Auto-Tracking

Every Friday at 5 PM, automatically message each OKR owner: "Please update your OKR progress." Sounds small, but it eliminates a massive amount of "reminding everyone to update OKRs" management overhead.

**Setup**: Use Feishu's built-in Automation Bot — set a weekly trigger → find all OKR records that haven't been updated → automatically send messages.

### Automation 2: Project Overdue Auto-Notification

When a project deadline is within 3 days and the task is not yet complete, automatically notify the project owner and manager.

**Setup**: Set a conditional trigger → check project status and deadline → if the condition is met, send a message to relevant people.

### Automation 3: New Customer Auto-Organization

When a salesperson adds a new customer record in the CRM, automatically:

1. Send a welcome message to the #sales channel
2. Assign the customer to the relevant salesperson
3. Generate a new customer introduction template

**Setup**: When a new row is added to the CRM table → trigger message notification and task assignment.
