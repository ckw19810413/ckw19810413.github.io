## 為什麼中小企業需要數位化？

假設你是一家 20 人的科技公司。你的團隊每天經歷這些場景：

## 7 天搭建計畫

不用一上來就搞大工程。以下是一個經過實戰驗證的 7 天搭建計畫，每天專注一個核心模組：

### Day 1：團隊基礎設定

**任務清單：**
- [ ] 建立飛書工作區，設定企業 Logo 和名稱
- [ ] 建立部門架構（工程、產品、市場、銷售、營運）
- [ ] 導入所有成員，設定角色和權限
- [ ] 建立基本頻道：#公告、#general、#random

**耗時：約 1 小時**

Day 1 的重點是打好地基。很多人會跳過這一步直接開始用功能，但基礎設定好壞，決定了後續所有工具的整合效果。

### Day 2：OKR 系統建立

**任務清單：**
- [ ] 建立公司級 OKR 模板（使用我們的 OKR 模板）
- [ ] 設定 Q3/Q4 目標與關鍵結果
- [ ] 各部門建立部門級 OKR
- [ ] 設定 OKR 追蹤頻率（建議每週）

**耗時：約 2 小時**

OKR 是整個數位工作區的「指揮中心」。有了 OKR，所有專案和任務都可以追溯到公司的戰略目標。不再出現「這個專案在做什麼」的困惑。

### Day 3：專案管理看板

**任務清單：**
- [ ] 為每個專案建立專案看板
- [ ] 設定專案流程：待處理 → 進行中 → 審查中 → 已完成
- [ ] 指派專案負責人和每個任務的負責人
- [ ] 設定專案截止日期和里程碑

**耗時：約 2 小時**

專案管理是飛書最強大的功能之一。它的內建看板（Lark Docs 的專案管理表）可以讓你看見所有專案的進度，而不需要切換到其他工具。

### Day 4：會議管理系統

**任務清單：**
- [ ] 建立每週例會的固定會議排程
- [ ] 建立會議模板（包含：上週回顧、本週目標、問題討論、行動項目）
- [ ] 設定會議記錄自動生成格式
- [ ] 訓練團隊在會議中使用「任務指派」功能

**耗時：約 1.5 小時**

好會議和好文件是兩回事。會議是「決定事情的場合」，會議記錄是「追蹤事情的憑證」。用飛書，你可以在會議中直接產生結構化的會議記錄，並自動生成行動項目追蹤。

### Day 5：CRM 客戶管理

**任務清單：**
- [ ] 建立客戶資料表（使用 CRM 模板）
- [ ] 設定客戶狀態漏斗：潛在客戶 → 接觸中 → 報價中 → 成交
- [ ] 為銷售團隊設定客戶分配規則
- [ ] 設定銷售儀表板

**耗時：約 2 小時**

CRM 是飛書最常被低估的模組。它的表格功能可以做到類似 Airtable 的資料庫管理，而且跟聊天和文件完美整合。你的銷售團隊不需要在 Excel 和 CRM 之間來回切換。

### Day 6：文件管理與知識庫

**任務清單：**
- [ ] 建立公司知識庫架構（按部門和主題分類）
- [ ] 導入現有文件（如果有的話）
- [ ] 設定文件權限管理
- [ ] 為每個部門建立「新人上手指南」

**耗時：約 1.5 小時**

知識庫是公司的「大腦」。好的知識庫讓新人在第一天就能找到所有需要的資訊，而不需要一個一個詢問同事。

### Day 7：自動化流程設定

**任務清單：**
- [ ] 設定 OKR 進度自動提醒（每周五）
- [ ] 設定專案逾期自動通知
- [ ] 設定新客户自動分配
- [ ] 建立常用表單（請假、報銷、採購）

**耗時：約 2 小時**

Day 7 是最有價值的一天。自動化流程一旦設定完成，就會自動運轉，不需要任何人維護。這才是數位化真正的「回報」——不是工具變多了，而是「重複性的管理動作變少了」。

## 必備模板清單

根據我協助多個團隊的實戰經驗，以下 4 套模板是中小企業營運的「最小必配集」：

### 1. OKR 追蹤模板

不只是「寫下目標」，而是建立完整的 OKR 追蹤循環：
- 公司級 OKR 看板
- 部門級 OKR 追蹤表
- 每週 OKR 進度更新模板
- OKR 季度回顧模板

有了 OKR，你不再需要「每週問大家的進度」這種低效管理。進度會自動反映在 OKR 表上。

### 2. 專案管理模板

- 專案初始化清單
- 專案看板（含自訂狀態欄）
- 專案風險追蹤表
- 專案收尾報告模板

專案管理的關鍵不在「列出任務」，而在「看見全貌」。好的模板應該讓你在 30 秒內就知道專案的健康狀況。

### 3. 會議記錄模板

- 會議預覽模板（會前自動發送）
- 會議記錄模板（含行動項目追蹤）
- 會議後續追蹤表

會議記錄最常被忽視的是「後續追蹤」。會議結束後的行動項目應該有一個地方被追蹤，而不是消失在聊天記錄裡。

### 4. CRM 客戶管理模板

- 客戶資料表（含公司資料、聯絡人、互動紀錄）
- 銷售漏斗儀表板
- 客戶分級管理
- 成交回顧模板

CRM 最重要的作用是「不要讓客戶資料只存在某一個人的腦袋裡」。換人、休假、甚至員工離職，客戶資料都不會消失。

## 自動化流程設定教學

數位化的最後一步、也是最關鍵的一步，是自動化。以下是最常設定的三個自動化流程：

### 自動化 1：OKR 進度自動追蹤

每個星期五下午 5 點，自動發送消息到每個 OKR 負責人：「請更新你的 OKR 進度」。這聽起來小事，但實際上消除了大量「提醒大家更新 OKR」的管理成本。

**設定方式**：使用飛書内建的 Automation Bot，設定每週觸發器 → 查找所有未更新的 OKR 記錄 → 自動發送消息。

### 自動化 2：專案逾期自動通知

當專案截止日期臨近 3 天且尚未完成時，自動通知專案負責人和主管。

**設定方式**：設定條件觸發器 → 檢查專案狀態和截止日期 → 若條件符合，發送消息給相關人員。

### 自動化 3：新客户資料自動整理

當業務在 CRM 表中新建一筆客戶資料時，自動：
1. 發送歡迎消息到 #sales 頻道
2. 將該客戶分配給對應的業務人員
3. 生成新客戶介紹模板

**設定方式**：當 CRM 表新增行時 → 觸發消息通知和任務分配。
